# Book Room for KOReader

Version 0.6.0 observes chapter changes and sends the latest normalized chapter
and table of contents to Book Room using KOReader's existing Progress Sync
connection.

## Compatibility

Verified with KOReader 2026.07.1 on Kobo. Other versions and devices are not
yet verified. The plugin checks for the required APIs at runtime and disables
an unavailable feature without interrupting reading.

## Use

1. In KOReader's Progress Sync settings, set the custom server to
   `https://sync.joinbookroom.com` and log in with credentials generated by
   Book Room.
2. Open an EPUB with a table of contents.
3. Choose **Tools → More tools → Book Room**.
4. Use **Send chapter now** for the first observation, then confirm the book
   and chapter mapping on the Book Room website.

The submenu also shows the current chapter, connection status, plugin version,
and table-of-contents diagnostics.

## Data and local state

The plugin sends the KOSync username and sync password as HTTPS authentication
headers. Its payload contains the document digest, device name and ID, reading
position and percentage, plugin version, current chapter, and normalized table
of contents. It does not access or send book text, annotations, highlights, or
notes.

The sync password is never displayed, logged, or stored by this plugin. The
latest local observation state is kept separately in
`settings/bookroom_observations.lua`; it can contain the username and payload
data, but not the sync password. Progress Sync settings remain in
`settings/kosync.lua`. Updating the plugin does not require deleting either
file.
